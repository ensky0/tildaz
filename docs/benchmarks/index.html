Benchmarks

TildaZ next to the terminals you know.

TildaZ v0.10.8, measured with the terminals people use on each OS: throughput, key-to-screen latency, memory, and startup time. The weak spots are in the tables too.

Linux macOS Windows Screenshots

How to read

Each OS stands on its own.

  • Compare terminals within one OS, not across OSes. The machines differ, and each OS reports latency and memory in its own way.
  • Linux and Windows ran on the same laptop. macOS ran on a MacBook Pro. All three displays ran at 120 Hz.
  • Bold is the best value in a row or column. The TildaZ column and row are highlighted.
  • † marks a terminal whose scrollback or grid could not be matched. It is left out when picking the best value for throughput and memory. Each OS lists the reasons below its tables.
  • ‡ marks a value from a terminal that drew that workload incorrectly. It is also left out when picking the best value. The screenshots show what each terminal drew.
MetricWhat it measures
ThroughputHow fast the terminal takes in and draws 64 MiB of output in a 120x40 grid with 32,767 lines of scrollback. The output starts one second after the window is ready, so startup work is not counted. Mean of five runs, without the fastest and the slowest.
Key-to-screen latencyFrom a synthetic key press to the first frame that changes, with the terminal idle. 150 presses per terminal. The 95th percentile (p95) shows the slow tail.
MemoryAll of the terminal's own processes, on an empty screen and after printing 40,000 lines. Idle CPU is the CPU time used over the next 30 seconds, where one core is 100%. Median of three runs.
StartupFrom launch to the first frame that shows the program running inside the terminal. Each app had been launched before (warm start). Median of five runs.

Ryzen AI 7 350 laptop · 120 Hz

Linux

TildaZ is first on Hangul and CJK output, and second to foot on plain text, ANSI color, and ZWJ emoji. On Hangul, TildaZ, Alacritty, and foot are within 1%. Emoji with VS-16 is its weak spot: of the terminals that draw ❤️ correctly, it is second, 4% behind kitty. It starts first. Once scrollback is full, it uses the least memory of the terminals with matching settings. foot has the lowest latency; TildaZ and kitty are tied for second.

Windows

TildaZ is first on plain text, ANSI color, Hangul, and CJK output. On ANSI color it is 44% ahead of Windows Terminal. Windows Terminal is 1.7 to 1.9 times as fast with emoji, and it draws the emoji correctly too. TildaZ has the lowest latency, just ahead of Windows Terminal. Leaving conhost aside, TildaZ uses the least memory, both on an empty screen and with scrollback full. Only conhost starts faster.

  • No first place on Windows comes from drawing less. Windows Terminal drew every workload correctly, so its lead on emoji is real. conhost is level with TildaZ on ZWJ emoji, but it draws three small monochrome people instead of one family emoji.
  • CJK and emoji with VS-16 varied more between runs, so each terminal ran five times. The table shows the mean of the middle three (#857).
  • ‡ The terminal drew that workload incorrectly, so the value is left out when picking the best. conhost and Alacritty draw emoji as monochrome outlines, split the family emoji, and pack Hangul narrower than two cells. WezTerm squeezes ❤️ into one cell. TildaZ and Windows Terminal drew every workload correctly. See the screenshots.
  • Without the one-second wait, TildaZ was 5–13% slower and Windows Terminal 6–19% slower, measured with v0.10.8 (#852).
  • † conhost has no scrollback: its buffer is the window.
  • Alacritty stops responding on the ZWJ workload on Windows. WezTerm was started with -n, which skips the user config.
  • The runs were pinned to the four fast CPU cores. This CPU mixes fast and small cores, and unpinned runs varied a lot. On Linux, pinned and unpinned runs gave the same results, so Linux was not pinned.
  • Latency and startup end at the time Windows reports the frame was presented (DXGI LastPresentTime).
  • Everything was measured after the laptop woke from sleep with the lid closed. Turning only the screen off was not enough. Right after a reboot, this laptop showed the first frame after an idle screen about 20 ms later, in every app (#836).

Method

Run it yourself.

  • TildaZ is the v0.10.8 release. The versions of the other terminals are listed under each OS.
  • Every run used AC power, with other windows minimized.
  • The scripts are compare-terminals.sh (throughput), compare-latency.sh, compare-memory.sh, and compare-startup.sh in tool/stress. Its README covers the setup and the pitfalls on each OS.
  • How each terminal drew the throughput workloads: screenshots.
  • Full results, including min, max, and grid sizes: #848. Earlier rounds: #826, #809, #756.
