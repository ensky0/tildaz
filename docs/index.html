Why TildaZ

The drop-down workflow people love, rebuilt for the desktops they actually use.

Instant

One key between thought and shell

Drop the terminal over your current workspace, run the command, and hide it again before your flow cools off.

Everywhere

Same reflex, every OS

Linux

Every major Wayland desktop

A direct Wayland client with no GTK or Qt runtime dependency. Real drop-down placement and global hotkey paths across major desktops, with package formats for common Linux distribution families.

  • KDE Plasma, GNOME, Cinnamon, COSMIC, Hyprland, sway
  • Fractional / HiDPI scaling, fcitx5 / IME support
  • tar.gz · deb · rpm · AppImage · Arch pkg (x86_64 / aarch64)

macOS

Native, Retina-sharp

Built on AppKit and Metal with full IME composition, candidate anchoring, and Hanja / kanji reconversion. Universal Apple Silicon + Intel.

  • Retina glyph rendering
  • Universal app bundle
  • Cursor-following drop-down on any display

Windows

Fast, native, bundled

GPU-accelerated rendering with a bundled Microsoft OpenConsole runtime for a consistent, modern terminal — x64 and ARM64.

  • Crisp ClearType glyph rendering
  • Bundled ConPTY for reliable shells
  • Win32 global hotkey and native window behavior

Numbers, not adjectives.

  • Read each column on its own. Linux and Windows are the same dual-boot laptop, so those two columns differ only in host implementation. macOS is a different machine, so reading straight across a row mixes in a CPU difference.
  • Built ReleaseFast with SIMD. Each run pours 64 MiB into a 120x40 grid with a 32,767-line scrollback on AC power, and every figure is the trimmed mean of five runs. The macOS column is v0.8.0; the Linux and Windows columns are later builds that include the fixes below, and each column's six figures come from a single session.
  • Linux is faster than the figures we first published. Its drain loop only woke on frame callbacks, so throughput scaled inversely with the display refresh rate. Issue #436 lets it carry straight on whenever output is still queued: re-measuring the same laptop moved ANSI from 22.9 to 56.7 MiB/s. Five of the six workloads gained between 1.5x and 2.5x. Plain ASCII was never held by that wait, and its before and after runs overlap, so we count it as unchanged.
  • Windows ANSI is fixed. It used to land on one of two speeds from run to run, because the Direct3D present call held the thread that parses output. Issue #435 replaced it with a waitable swap chain: ANSI went 37.3 to 65.2 MiB/s, and the spread across five runs fell from 214% to 8%. macOS was never affected.
  • Harness, workloads, and the full method: dist/stress.

Get Started

Download, install, press F1.

1

Download

Grab the latest GitHub Release for your OS: a Linux package (deb / rpm / AppImage / Arch / tar.gz), macOS DMG, or Windows zip.

2

Install

Linux: install the package or run ./install.sh from the tarball. macOS: drag the app into Applications. Windows: unzip and run.

3

Press F1

Drop the terminal down with the hotkey. Tweak config_0.json for shell, theme, font, hotkey, opacity, and geometry. Launch TildaZ again to add another independently configured instance.
