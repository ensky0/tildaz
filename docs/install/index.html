Install TildaZ

Install the native drop-down terminal with one command.

One command installs TildaZ on Linux, macOS, and Windows, then starts it. Press F1 and your terminal drops down. Prefer a package? Every release also ships deb, rpm, AppImage, Arch pkg, DMG, and zip builds.

Quick Install All Downloads

Quick Install

One command installs and starts TildaZ.

# Linux and macOS
curl -LsSf https://ensky0.github.io/tildaz/install.sh | sh
# Windows
powershell -ExecutionPolicy ByPass -c "irm https://ensky0.github.io/tildaz/install.ps1 | iex"

The script downloads the latest release, checks its SHA-256, installs it into your user account, and adds TildaZ to your app menu. No sudo or admin rights are needed. It then starts TildaZ once, and TildaZ sets up auto-start on that first run. On GNOME, log out and back in first so the Shell extension loads. Read the scripts first: install.sh, install.ps1.

PlatformInstalls to
Linux~/.local/share/tildaz, plus the app menu entry and ~/.local/bin/tildaz
macOS/Applications/TildaZ.app (~/Applications if /Applications is not writable)
Windows%LOCALAPPDATA%\Programs\TildaZ, plus a Start Menu shortcut
  • Already installed a Linux package or AppImage? Keep updating it that way. The script stops instead of installing a second copy next to it.
  • Used the Windows zip before? Quit it first. The script tells you where the old folder is, and your config carries over.

Update and Uninstall

Run the same command to update.

To update, quit TildaZ and run the install command again. Your config is kept. To uninstall, quit TildaZ and run the uninstaller. It keeps your config and logs, and prints where they are.

# Linux and macOS
curl -LsSf https://ensky0.github.io/tildaz/uninstall.sh | sh
# Windows
powershell -ExecutionPolicy ByPass -c "irm https://ensky0.github.io/tildaz/uninstall.ps1 | iex"

Packages

Or download a package.

Linux

Choose your package

Use a portable tarball, deb, rpm, AppImage, or Arch pkg. Linux builds target common distribution families and include x86_64 / aarch64 where the release provides them. From the tarball, run ./install.sh --release. On GNOME, the bundled Shell extension loads only after you log out and back in once. Cinnamon loads it right away.

  • tar.gz for portable installs
  • deb for Debian / Ubuntu
  • rpm for Fedora / RHEL / openSUSE
  • AppImage for a single-file launch
  • Arch pkg for Arch-family systems
macOS

Drag the app in

Download the universal DMG and drag TildaZ.app into Applications. Releases use a stable self-signed TildaZ identity rather than Apple notarization, so use macOS's Open action if Gatekeeper blocks the first launch. Then grant Input Monitoring and Device Control and Data Access (called Accessibility before macOS 27) for the global hotkey and window control shortcuts.

  • macOS 14+
  • Apple Silicon + Intel
  • AppKit + Metal host
Windows

Unzip and run

Download the x64 or ARM64 zip, keep the _internal folder next to tildaz.exe, and run tildaz.exe.

  • Windows 10 1809+ x64 (the bundled ConPTY's minimum; tested on Windows 11)
  • Windows 11 ARM64
  • Bundled Microsoft OpenConsole runtime

After Install

First launch creates your config.

PlatformConfigLog
Linux$XDG_CONFIG_HOME/tildaz/config_0.toml$XDG_STATE_HOME/tildaz/tildaz_0.log
macOS$XDG_CONFIG_HOME/tildaz/config_0.toml~/Library/Logs/tildaz/tildaz_0.log
Windows%APPDATA%\tildaz\config_0.toml%APPDATA%\tildaz\tildaz_0.log

On Linux and macOS, XDG_CONFIG_HOME defaults to ~/.config. On Linux, XDG_STATE_HOME defaults to ~/.local/state. Empty or relative values use those defaults.
