Benchmarks

TildaZ next to the terminals you know.

TildaZ v0.10.7, measured with the terminals people use on each OS: throughput, key-to-screen latency, memory, and startup time. The weak spots are in the tables too.

Linux macOS Windows

How to read

Each OS stands on its own.

  • Compare terminals within one OS, not across OSes. The machines differ, and each OS reports latency and memory in its own way.
  • Linux and Windows ran on the same laptop. macOS ran on a MacBook Pro. All three displays ran at 120 Hz.
  • Bold is the best value in a row or column. The TildaZ column and row are highlighted.
  • † marks a terminal whose scrollback or grid could not be matched. It is left out when picking the best value for throughput and memory. Each OS lists the reasons below its tables.
MetricWhat it measures
ThroughputHow fast the terminal takes in and draws 64 MiB of output in a 120x40 grid with 32,767 lines of scrollback. Mean of five runs, without the fastest and the slowest.
Key-to-screen latencyFrom a synthetic key press to the first frame that changes, with the terminal idle. 150 presses per terminal. The 95th percentile (p95) shows the slow tail.
MemoryAll of the terminal's own processes, on an empty screen and after printing 40,000 lines. Idle CPU is the CPU time used over the next 30 seconds, where one core is 100%. Median of three runs.
StartupFrom launch to the first frame that shows the program running inside the terminal. Each app had been launched before (warm start). Median of five runs.

Ryzen AI 7 350 laptop · 120 Hz

Linux

TildaZ is first on CJK output and second to foot on plain text, ANSI color, and ZWJ emoji. On Hangul it is tied with Alacritty and foot. Emoji with VS-16 is its weak spot: it is third, at 95% of Alacritty. It starts first on each desktop. Once scrollback is full, it uses the least memory of the terminals with matching settings. On KDE Plasma, foot has the lowest latency and TildaZ is second. On GNOME, TildaZ has the lowest latency. On COSMIC, it is tied with Alacritty.

  • Throughput and memory come from KDE Plasma only. On its own desktop, GNOME Terminal was 46% faster with plain text (68.3 vs 46.7 MiB/s). COSMIC Terminal was about the same on both.
  • Latency and startup were measured on each desktop. Do not compare them across desktops. On Linux, both end when the frame reaches the capture tool. KDE Plasma and GNOME pass a frame to it as soon as they compose it. COSMIC passes it after the frame is on the screen.

  • Startup opens each terminal's desktop entry: kioclient exec on KDE Plasma, gio launch on GNOME and COSMIC.

MacBook Pro M5 Pro · 120 Hz

macOS

Ghostty 1.4.0 is first on every throughput workload. TildaZ is second on Hangul and emoji output, and third on the rest. It starts fastest and uses the least memory of the terminals with matching settings. Latency is its weak spot: fourth of seven, about 6 ms behind Alacritty and kitty.

Ryzen AI 7 350 laptop · 120 Hz

Windows

TildaZ is first on plain text, Hangul, and CJK output. Windows Terminal is almost twice as fast with emoji, and slightly faster with ANSI color. The two tie on latency. Leaving conhost aside, TildaZ uses the least memory, both on an empty screen and with scrollback full. Only conhost starts faster.

Method

Run it yourself.

  • TildaZ is the v0.10.7 release. The versions of the other terminals are listed under each OS.
  • Every run used AC power, with other windows minimized.
  • The scripts are compare-terminals.sh (throughput), compare-latency.sh, compare-memory.sh, and compare-startup.sh in tool/stress. Its README covers the setup and the pitfalls on each OS.
  • Full results, including min, max, and grid sizes: #826. Earlier rounds: #809, #756.
