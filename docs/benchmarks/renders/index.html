How to read

Same output, different pictures.

  • Each picture is the last screen of an 8 MiB run of the throughput workload. These runs were separate from the timed runs, because taking a screenshot uses CPU.
  • Each card shows the top left of the window. Select it to open the full screenshot.
  • Correct means one color glyph per emoji, two cells wide. Anything else is described in a few words.

Linux

TildaZ, foot, Ghostty and Konsole drew every workload correctly. kitty drew the right glyphs in much wider cells. Alacritty and GNOME Terminal split the family emoji into separate people, and WezTerm and GNOME Terminal squeezed ❤️ into one cell. Alacritty is the fastest on VS-16 emoji, but it draws that heart as a white outline in one cell.

macOS

TildaZ, kitty, Ghostty and iTerm2 drew every workload correctly. Alacritty drew emoji as small monochrome outlines and split the family emoji into separate people. WezTerm squeezed ❤️ into one cell, and Terminal.app drew emoji at the wrong width, so the text after them shifts. No first place in the macOS throughput table comes from drawing less.
